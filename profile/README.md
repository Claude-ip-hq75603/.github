<p>这份说明书是给"反复起号"的卖家看的：账号被限制后，需要快速换一批干净出口重开，最怕新买的地址和上一批撞在同一段上。下面五个参数决定这件事的概率和成本——池子规模、段数分布、复用率、静态与轮换的差别、以及带宽与并发。每个参数都给取值范围、自查方法和一句取值建议，最后压缩成一张速查表，采购前照着对一遍就行。</p>

<h2>一、这份说明书怎么读</h2>
<p>参数不是越多越好，而是越清楚越好。供应商能报出的参数越具体，你在采购前能排除的风险越多。</p>
<h3>先分清"能查的"和"要问的"</h3>
<p>归属、ASN、段号这些可以自己查：<code>whois 地址</code>、<code>ping</code> 反解、公开情报页，一分钟能验证。池子规模、复用率、回收周期这三项查不到，只能问供应商，答案的颗粒度本身就是筛选标准。</p>
<h3>参数之间会互相牵制</h3>
<p>池子大但复用率高，等于没用；复用率低但段数少，新的地址还是落在同一段里。评估时要两项一起看，不能单看一个数字漂亮就下单。</p>

<h2>二、池子规模、段数与复用率</h2>
<img src="/tp.png" alt="Claude 反复起号场景下住宅出口池规模与段分布的参数说明">
<p>这三个参数共同决定"换一批"是否真的换掉了环境。很多供应商说"池子一万条"，但这一万条挤在几十个 /24 里，撞段概率并不低。</p>
<h3>池子规模看"可用条数"，不看总量</h3>
<p>问清楚当前可分配多少条、其中静态独享多少条。总量里往往混着大量轮换池地址，不能用于长期挂号。可分配条数才是你能调用的资源。</p>
<h3>段数分布决定撞段概率</h3>
<p>一个 /24 有 256 个地址，实际可用的通常更少。若一万条地址分布在四十个 /24 里，平均每段两百多条，同一段被重复分配的概率很高。粗略估算方法：段数除以你所需的地址数，结果小于十就要警惕。买之前直接问"这些地址分布在多少个 /24 里"。</p>
<h3>复用率与回收周期</h3>
<p>复用率指同一地址在单位时间内被分配给不同客户的次数。回收周期指客户退租后多久重新进入可分配池。两项都低的供应商更贵，但对反复起号的场景更划算。要问的具体问题：上一位使用者退租到现在多久、这条地址近三个月被分配过几次。</p>

<h2>三、静态、轮换与切换冷却</h2>
<p>这三项决定"什么时候换"和"换了之后多久才能用"。搞错了，换线动作本身就会成为新的异常信号。</p>
<h3>静态适合挂号，轮换适合采集</h3>
<p>需要长期登录的账号必须用静态地址，一号一条，长期不变。轮换池适合一次性抓取或临时任务，不要用来登录。混用是最常见的错误：为了省钱让登录环境走轮换，结果每次登录都在换城市。</p>
<h3>切换冷却至少留一天</h3>
<p>同一账号换到新地址后，建议至少间隔二十四小时再做重要操作。更保守的做法是先做几次普通对话，让新环境有一段可解释的活动记录，再处理订阅、设置这类敏感动作。</p>

<h2>四、带宽、并发与地区覆盖</h2>
<p>这三项影响的是体验上限，不是能不能用。但它们会间接影响稳定性，因为带宽不足会导致超时，超时又会被误判成环境问题。</p>
<h3>带宽看上行，不只看下行</h3>
<p>家庭宽带的上行通常远小于下行。后台操作以请求为主，上行拥塞时表现是提交按钮转圈。问清上行带宽，标称 50Mbps 的线路，上行可能只有 10Mbps 甚至更低。</p>
<h3>并发按线路计，不按账号计</h3>
<p>一条静态地址建议同一时刻只承载一个登录态。要并行更多账号，就按峰值活跃数加线，而不是在一条线上堆。参考资料：五到八个活跃账号通常需要五到八条线，加一到两条冷备用。</p>
<h3>地区覆盖要落到城市</h3>
<p>"支持美国"这个描述太粗。要问清能指定到哪个城市、同城有多少条可选。反复起号的场景建议一次锁定两到三个城市，避免全部集中在同一个城市导致新的聚集特征。</p>

<h3>采购时的三句话</h3>
<p>把这三句直接问出去，答不上来的可以直接排除：这些地址分布在多少个 /24 里；每条地址近三个月被分配过几次；同城还有多少条可指定。三个答案都具体，基本可以进入试用。</p>
<h3>试用期看两个动作</h3>
<p>一是只做登录，观察是否需要额外验证；二是换一条新地址重复同一动作，看表现是否一致。两次都顺，才说明池子的整体质量稳定，而不是碰巧分到一条好线。</p>

<h2>常见问答</h2>
<h3>池子越大，撞段的概率就一定越低吗？</h3>
<p>答：不一定。要看地址分布在多少个段里。一万条挤在二十个 /24 中，撞段概率可能高于两千条分布在两百个段里。判断标准是段数，不是总条数。</p>
<h3>供应商说"独享"，怎么验证？</h3>
<p>答：独享是指这条地址只分配给你。验证方法有限，只能靠间接判断：问是否有分配记录、试用期内表现是否稳定、其他客户退租后是否立刻回收给你。三个问题答案含糊的，按共享对待。</p>
<h3>反复起号时，一批用多少条比较合适？</h3>
<p>答：按这批要起的账号数配，再加三成余量。余量的作用是遇到个别地址不可用时不用临时采购。一次买太多会拉高闲置成本，太少则失去腾挪空间。</p>
<h3>换新地址后多久可以正常使用？</h3>
<p>答：技术上一分钟就能用，实际操作建议留观察期。先做几次普通操作，确认无额外验证，再处理订阅和设置。二十四小时是比较稳妥的间隔，急着用至少也留几个小时。</p>
